# dsc200-fa26-public

Course materials for **DSC 200: Data Science Programming** (Fall 2026, UC San Diego).

> **Status: DRAFT.** This is the working skeleton for the FA26 refresh. These files are intended to become the root of the `dsc200-fa26-public` repository.

## What changed from FA25

FA25 spent roughly half the quarter on the PyData API surface (NumPy/Pandas/matplotlib/xarray) and half on classical data structures and algorithms, with generative AI banned in assignments. FA26 inverts that stance: AI-assisted (agentic) coding is the default way code gets written, and the course teaches the skills that still matter when an agent writes most of the code — specifying, structuring, validating, and judging it. The redesign is organized around Andrew Ng's AI Engineering Skills Map (The Batch, Aug 2026): *using coding agents*, *software engineering fundamentals*, and *shaping the build*, with a light touch of LLM foundations (ML fundamentals live in other DSC courses).
